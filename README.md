# 📖 Project Overview

> [!IMPORTANT]  
> **COTATO Official Website**는 IT 연합 동아리 코테이토의 활동을 한눈에 볼 수 있게 기록하고  
> 동아리 운영 및 활동에 필요한 기능을 통합 제공하도록 설계된 코테이토의 공식 홈페이지입니다.

기존 홈페이지의 활동 아카이빙 부재와 불편한 점을 개선한 **코테이토 공식 홈페이지 UX/UI 리뉴얼 프로젝트**입니다. <br>
이번 **리뉴얼 프로젝트**는 사용자 중심의 설계를 통해 동아리의 가치를 명확히 전달하고 운영 효율을 극대화하는 데 집중했습니다.
